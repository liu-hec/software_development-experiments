### 2. Anaconda（Jupyter Notebook）安装

1. 下载 Anaconda 安装包

    https://www.anaconda.com/download/  下载 或者使用镜像源下载

2. 安装配置：

    - 路径无中文、无空格
    - 选择 just for me 否则需要管理员权限
    - 使用 Anaconda 作为默认 Python 环境

    ![image-20260423204309380](C:\Users\86152\AppData\Roaming\Typora\typora-user-images\image-20260423204309380.png)

    ![image-20260423204330172](C:\Users\86152\AppData\Roaming\Typora\typora-user-images\image-20260423204330172.png)

    配置环境变量 

    将安装的地址的加入到系统的环境变量

    ```
    D:\anaconda3
    D:\anaconda3\Scripts
    D:\anaconda3\Library\bin
    D:\anaconda3\Library\mingw-w64\bin
    ```

    

3. 安装验证：

     搜索prompt ,点击anaconda prompt 或者anaconda Powershell Prompt,输入conda  --version

    ![image-20260423205007157](C:\Users\86152\AppData\Roaming\Typora\typora-user-images\image-20260423205007157.png)

    

    

    

4. 安装和启动 Jupyter Notebook：

    在anaconda 的环境下安装Jupyter Notebook

    4.1 创建虚拟环境 

    ```
    conda create --name jupyter_learn 替换为自己的取名的名字
    conda env list 查看是否创建成功
    ```

    ![image-20260423205254544](C:\Users\86152\AppData\Roaming\Typora\typora-user-images\image-20260423205254544.png)

    看到my_jupter意味着创建成功

    

    4.2 启动

    ```
    jupyter notebook
    ```

    ![image-20260423205508615](C:\Users\86152\AppData\Roaming\Typora\typora-user-images\image-20260423205508615.png)

    自动跳转到浏览器，安装成功

    

    默认是c盘目录的内容，如何修改呢？

    ```
    jupyter notebook --generate-config
    ```

    找到对于的配置文件.py  修改ServerApp.notebook_dir

    ```
    c.ServerApp.notebook_dir = 'D:/jupyterProjects'
    ```

![image-20260423211148777](C:\Users\86152\AppData\Roaming\Typora\typora-user-images\image-20260423211148777.png)

  这样，进入的就是定向的文件夹
